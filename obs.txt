Output Interface: std::vector<DefectComponent> (Filtered Area >= 270px)
INPUT RES: 256X256
RGB; SQUARE PADDED WARPED TO 256X256
crop is done on raw RGB image 

ROI CROPPING LOGIC: 
1. map output from layer1 using centroid distance NMS
2. if defect is less than 256x256; just expand. if defect is bigger, then simply tile at 128px stride(50%overlap)
- P1: 
  all boxes with area > 350px  
- P2: priority based off of clusterScore 
  270 px < area < 350 px
  BFS centroid distance < 120px
  when merging; combined bounding box shouldn't exceed 200x200. provides a safety margin for layer2(if defects fall at the edge)
  calculate clusterScore: total area x density (this gives more priority to densely flagged areas)
- P3: 
  if centroid dist bw cluster and new point is less than 120px; and total bounding box is under 200px: merge
  if centroid dist is bw 120-180px and results in a bounding box under 200px: shift and merge
  otherwise a separate bounding box

A reasonable MVP target would be:
- 500–1000 positive ROIs
- 500–1000 negative ROIs

Negatives should include:
- weave texture
- lighting variation
- shadows
- wrinkles
- harmless texture changes
- every kind of false alarm Layer 1 produces
